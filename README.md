🚀 CRM SaaS

A modern Customer Relationship Management (CRM) application built with the MERN Stack.
This application helps businesses efficiently manage customers and tasks through a clean, responsive, and secure interface.

---

✨ Features

- 🔐 JWT Authentication
- 🍪 Secure HTTP-Only Cookie Authentication
- 👤 User Registration & Login
- 📊 Interactive Dashboard
- 👥 Customer Management (CRUD)
- ✅ Task Management (CRUD)
- 🔍 Search & Filter Tasks
- 🎯 Task Priority & Status Management
- 📅 Task Completion Date
- 🎨 Dynamic Avatar Generation
- 📱 Fully Responsive Design
- 🛡️ Protected Routes
- ☁️ MongoDB Atlas Integration
- 🚀 Live Deployment on Render

---

🛠️ Tech Stack

Frontend

- React.js
- React Router DOM
- Axios
- CSS

Backend

- Node.js
- Express.js
- MongoDB Atlas
- Mongoose
- JWT Authentication
- bcrypt
- Cookie Parser
- CORS
